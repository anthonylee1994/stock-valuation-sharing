## 附錄：計算公式速查

### P/E倍數計算

```
P/E倍數 = 股價 ÷ 每股盈利(EPS)
```

### 目標價計算

```
目標價 = 未來EPS × 目標P/E倍數
```

### 上漲空間計算

```
上漲空間 = (目標價 - 當前股價) ÷ 當前股價 × 100%
```

### 期望報酬計算

```
期望報酬 = Σ(情境報酬率 × 情境概率)
```
